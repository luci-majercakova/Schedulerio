
# Schedulerio - Your Uni Schedule Studio

Use at: <https://luci-majercakova.github.io/Schedulerio/>

## Turn your lesson plan into a pretty timetable!

Customize the lesson information, background, time-format, colors, vertical vs horizontal settings and more.

Download the picture of your timetable in high resolution. Download your project file so you can continue with your work later.

Upload your schedule in .ics/.txt file, paste the text content or follow instructions to extract the information from an image.



## Dev info:

Vibecoded with Google AI Studio with details later directly customized by me.

Background images come from pixabay.



## Run Locally:

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
